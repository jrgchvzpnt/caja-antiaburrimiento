# Caja Antiaburrimiento — landing page

Página de presentación de **Caja Antiaburrimiento**, una app para Android con 13 juguetes animados para cuando estás aburrido: pop-it, pintar con fuegos artificiales, atrapa pompas, retos reales, la bola que decide, Simón dice, parejas, reflejos, piano de colores, golpea al topo, serpiente, tres en raya y salva los globos.

Sitio: https://jrgchvzpnt.github.io/caja-antiaburrimiento/

Es un único `index.html` sin dependencias de compilación. GitHub Pages lo sirve directamente desde la rama `main`.
